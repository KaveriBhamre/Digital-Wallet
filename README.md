## CLI Based Digital Wallet 

💳 Digital Wallet

A Java-based Digital Wallet application that allows users to manage their wallet, perform transactions, check balances, and maintain transaction history.

🚀 Features
User & wallet management
Add / withdraw money
Money transfers
Balance management
Transaction history
Group Management
Split Expenses

🛠️ Technologies
Java
OOP
Collections
Exception Handling

🎯 Purpose

Built to demonstrate practical Core Java and OOP concepts through a real-world digital payment application.
